What is CardFly?

CardFly Studio is a visual editor for student cards. You lay out the front and back of a card using text, images and shapes, define variables (name, school, id, photo…), bind them to layers, and export the result as SVG or PNG. The 3D preview shows the card as a physical object.

The editor

  • Left tab — Elements: drag text or an image onto the canvas, or right-click a layer and bind a variable.
  • Left tab — Variables: define the required fields every card must have, and bind them to layers. The Bridge button can pull variables straight from a Python generator.
  • Left tab — Layers: paint order (top = front).
  • Right panel — Properties: position, size, font, colour and binding for the selected layer.
  • Toolbar: open a template folder, export (SVG with or without values filled, PNG), and open the 3D preview.

Variables are written into the SVG as {name} placeholders. CardFly detects every {…} automatically so you can lay out and bind values before exporting.

3D preview

Open the 3D preview to see your card as a physical student card. The camera fits the card to the viewport and keeps it centred regardless of screen size. Drag to orbit, scroll to zoom. Pick a backdrop colour from the top bar.

Python generator & the @card decorator

Write a Python function that produces a card, and decorate it with @card. CardFly reads the function's signature — parameter names, defaults, type hints and Field(...) metadata — and builds the card's variable interface automatically.

from cardgen import card, Field, Image, Choice, serve @card(name="Student Card", template="front.card.kaascan") def generate_student_card( full_name: str, id_number: Field(str, label="Student ID", required=True, help="Unique student/registration number."), year: int = 2025, photo: Image = Image, grade: Choice("A", "B", "C") = Choice("A", "B", "C"), active: bool = True, ) -> str: return '<svg ...>...</svg>' if __name__ == "__main__": serve()

Connecting the generator to the editor

cardgen exposes the contract over HTTP, so the editor can read it without any file round-trip. The flow is:

  1. Run your generator script: python3 my_card.py — cardgen starts a tiny listener on http://127.0.0.1:8123.
  2. In CardFly Studio open the Variables tab → Bridge → Listen (or open http://127.0.0.1:8123/docs.html in a browser).
  3. The editor fetches the contract and pre-fills the Variables tab.

Endpoints served by the bridge:

RouteReturns
/Mini index (JSON) listing both endpoints.
/__card__variable_contract__JSON contract of every card + its variables.
/__card__docs__This documentation page (HTML).

You can also emit a contract file without running the server: python3 cardgen.py my_card.py --emit contract.json.
